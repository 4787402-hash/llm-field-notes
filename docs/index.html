Measured, not guessed

The benchmark numbers behind these notes come from a single machine: AMD RX 6700 XT 12 GB, Ryzen 5 5600G, 16 GB RAM, llama.cpp Vulkan backend, Qwen2.5 7B at Q4_K_M.

  • Full benchmark table prefill, generation, KV quantization, context growth
  • Do not enable KV cache quantization on the Vulkan backend
  • Prefill time is quadratic, and it dominates agent workloads
