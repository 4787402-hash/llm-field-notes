Codex: `wire_api = "chat"` is no longer supported

`wire_api = "chat"` is no longer supported

Where: OpenAI Codex CLI 0.170.0+, custom provider in ~/.codex/config.toml

What you see

You pointed Codex at a local or third-party OpenAI-compatible endpoint with wire_api = "chat" and it refuses to start.

Why it happens

Codex 0.170 dropped the Chat Completions wire protocol for custom providers. Only the Responses API is accepted now. Most local servers (llama.cpp, LM Studio, vLLM, LiteLLM) expose both, so this is usually a one-line config change.

Fix

  1. In ~/.codex/config.toml, set wire_api = "responses" under your provider block.
  2. Do not name the provider openai. That id is reserved and a custom block with it fails to parse with config could not be loaded.
  3. For a purely local model you can skip the provider entirely and use codex --oss --local-provider ollama (or lmstudio).

Verification

Verified against Codex 0.170.0 with a LiteLLM proxy exposing /v1/responses. Config parses, doctor passes, and a real task completes end to end.
